# Требования к практической части

---

<aside>
🚨

Программы должны запрашивать ввод данных от пользователя и выводить результаты на экран **с пояснениями** вводимой и выводимой информации.

</aside>

<aside>
🚨

**КАЖДОЕ ЗАДАНИЕ** должно находится в **ОТДЕЛЬНОМ** репозитории с именем `ipo-lrX-V-Y` где `X` — это номер ЛР, `V` — вариант, а `Y` — номер задания.

</aside>

<aside>
🚨

Репозиторий должен содержать файл [**README.md](http://README.md)** с текстом задачи, отформатированным логическим образом. 

</aside>

<aside>
🚨

 Главный файл должен называться `index.py` , в котором выполняется функция `main()` , все остальные действия находятся внутри функции `main()` 

</aside>

# Общие задания

---

## Задание 1

Создать новую ветку `feature/func` в репозитории с заданием :

[Задание 3](https://www.notion.so/3-96ec4e90e2604c0c81f85c713e6d47fe?pvs=21) 

Изменить программу, весь функционал задания реализовать с помощью **функций**.

<aside>
🚨

Меню, функции добавление, удаления и тд. должны быть оформлены в разных функциях

</aside>

<aside>
💡

Замете, данные которые вводит пользователь должны проверятся на корректность

</aside>

## Задание 2

Соединить ветку `feature/func` в ветку `main`
